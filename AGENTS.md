# AGENTS.md

## Проект

- `losthost/telle` — фреймворк для Telegram-ботов (getUpdates/webhook, worker-процессы, планировщик).
- Используется ботами через composer (например, `Oberbot`). Правки делаются здесь, а не в `vendor/` потребителей.
- Источник истины — фактический код.

## Правила изменений

- Перед кодовым шагом проверять чистоту дерева.
- Изменение контракта начинать с документации (`README.md`), затем fail-first тесты, затем код.
- Тесты: `php tests/run.php`.
- Не добавлять fallback, compatibility path и эвристики без согласования.
